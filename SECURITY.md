# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my repositories, please report it responsibly.

### How to Report

1. Open a GitHub Issue with `[SECURITY]` prefix in the title
2. Do NOT include sensitive details in the public issue
3. I will acknowledge receipt within 48 hours

### What to Expect

- Acknowledgment within 48 hours
- Assessment and triage within 7 days
- Fix and disclosure timeline agreed upon

### Responsible Disclosure

Please allow reasonable time for a fix before public disclosure.
